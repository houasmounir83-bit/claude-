# رفّ الكتب — صفحة هبوط

صفحة هبوط عربية (RTL) لبيع ثلاثة كتب، بملف واحد `index.html` وصور في `images/`.

## التعديل
في أعلى السكربت داخل `index.html`:
- `CONFIG.whatsapp`: رقم واتساب بالصيغة الدولية (مثال `213551234567`).
- `price` لكل كتاب في `BOOKS` (0 = "السعر عند الطلب").

افتح `index.html` في المتصفح أو انشره على GitHub Pages.

## المتجر المتطور — `store.html`
نسخة متجر كاملة بنفس الهوية:
- بحث فوري، تصفية حسب التصنيف، وترتيب (السعر، التقييم، الأكثر طلبًا).
- عرض سريع لكل كتاب مع معرض صور واختيار الكمية والمخزون.
- سلة جانبية محفوظة على الجهاز، ومفضلة، وسجل «طلباتي».
- صفحة طلب: 58 ولاية برسوم توصيل حسب المنطقة (منزل / مكتب)، أكواد خصم، خصم الكمية، وتوصيل مجاني فوق حد معيّن.
- يُرسَل الطلب برقم مرجعي إلى واتساب، مع وضع ليلي وتصميم متجاوب للهاتف.

### الإعداد
في أعلى السكربت داخل `store.html`:
- `CONFIG.whatsapp`: رقم واتساب الدولي.
- `CONFIG.shipping`: أسعار التوصيل لكل منطقة، و`WILAYAS` تحدد منطقة كل ولاية.
- `CONFIG.coupons`: أكواد الخصم، و`CONFIG.freeShippingFrom` و`CONFIG.bundleDiscount`.
- `PRODUCTS`: الأسعار (`price`, `oldPrice`)، المخزون `stock`، التقييمات. **الأسعار الحالية أمثلة — غيّرها.**
