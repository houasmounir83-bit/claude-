# موقع NOVIPACK

صفحة واحدة (`index.html`) مع الصور في `images/`.

## قبل النشر
في أسفل `index.html` داخل `CONFIG`:
- `whatsapp`: رقم واتساب بالصيغة الدولية بدون + وبدون 0 (مثال `213551234567`).
- `phoneDisplay`: الرقم كما يظهر للزبون.
- `price` لكل منتج في `PRODUCTS` بالدينار (0 = «السعر عند الطلب»).

`body.html` نفس المحتوى بدون غلاف الصفحة (للمعاينة).
