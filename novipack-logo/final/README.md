# NOVIPACK — الشعار النهائي

| المجلد | المحتوى | الاستعمال |
|---|---|---|
| `horizontal/` | الشعار الأفقي: ملوّن، أبيض، على خلفية زرقاء، نسخة بالعربية، بدون سطر | الموقع، الفواتير، العلب، الإعلانات |
| `stacked/` | الرمز فوق الاسم + «نوفي باك» | الملصقات المربعة، واجهة المحل |
| `one-color/` | لون واحد: أزرق، أسود، أبيض | طباعة الكرتون والختم والأكياس بلون واحد |
| `icon/` | الأيقونة، الأيقونة بلون واحد، favicon (32/180/512)، صورة الحساب 1080 | فيسبوك، إنستغرام، واتساب، أيقونة الموقع |

- **SVG**: للمطبعة (يكبر بلا حدود، الكتابة محوّلة إلى أشكال).
- **PNG**: بخلفية شفافة للاستعمال المباشر.

الخط: Bricolage Grotesque ExtraBold (لاتيني) · Readex Pro Bold (عربي)
